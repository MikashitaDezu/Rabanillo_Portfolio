## Projects

### LibraGuard (capstone, project lead and IoT architect)
A smart library system that combines ESP32 devices, a web portal and a Flutter mobile app. It handles patron check-ins, book monitoring and library noise monitoring.

- Hardware: ESP32, MFRC522 RFID, MAX4466 sound sensor, LEDs, buzzer and push buttons
- Software: web portal hosted on Vercel, Flutter (Dart) mobile app
- [Live system](https://libraguard-system.vercel.app/)
